# 미션: AI 데이터 분석, 데이터 기반 트렌드 분석

> 원문: Notion(hlnt) 미션 페이지. 브랜치 `a2-1`에서 수행한다. 후속 미션(AI Agent 개발)은 `a2-2`.

## 1. 미션 소개
시계열 데이터에서 패턴을 발견하고 "그래서 이게 무슨 의미인가"를 스스로 해석한다.
데이터를 정제하고, 시각화하고, 패턴을 발견해 의사결정에 쓸 수 있는 인사이트 리포트를 작성한다.

## 2. 최종 결과물
- **분석 리포트(Markdown)**: 시계열 데이터(최소 100개 데이터 포인트). `REPORT.md`에 분석 주제, 질문, 데이터 설명, 시각화, 인사이트, 결론/한계점 포함
- **시각화**: 필수 2개 이상, 권장 3개 이상. 이미지 파일(png 등)을 리포트에 포함(링크 정상 동작)
- **Python 코드**: 원본 데이터 파일 또는 수집 스크립트 → `.ipynb` 또는 `.py`
- **GitHub 저장소**: 코드, 리포트, (가능한 범위 내) 데이터 또는 데이터 수집 방법 문서

## 3. 과제 목표
- 데이터 분석 사고: 질문 3개 이상 정의 / 결측치·이상치 처리 기준 설명 / 관찰(사실)과 해석(가설) 구분
- 시계열 이해: 트렌드·계절성·노이즈 설명 / 이동평균·변화율 등을 왜·어떻게 적용했는지 설명
- AI 활용: 목적에 맞는 질문을 AI에게 던지고 생성된 코드·해석을 검증 / 최종 판단은 본인이 근거로 설명

## 4. 기능 요구 사항
1. **주제·데이터 선정**: 시계열 1개, 최소 100개 포인트, 출처와 기간 명시
2. **분석 질문**: 3개 이상
3. **정제·분석**: 기본 정보(기간·컬럼·결측치) 확인, 결측치·이상치 기준을 정해 처리, 시계열 기법 최소 2가지(이동평균, 변화율, 구간 통계, 변동성, 월별·요일별 집계 등)
4. **시각화**: 필수 2개, 권장 3개 이상
5. **인사이트·리포트**: 인사이트 3개 이상, 각각 그래프의 관찰(수치·근거) 포함

## 5. 보너스 과제
- **서비스화**: 기간·조건을 바꿔 보는 웹 대시보드. 배포 URL / 로컬 실행 녹화+실행 방법 / 스크린샷+시나리오 중 택1
- **시계열 심화**: (A) 분해(추세·계절성) 또는 (B) 베이스라인 예측(정확도보다 가정·한계 설명) 중 1개 이상 + 시각화 1개 이상

## 6. 개발 환경
Python 3.10 이상, Jupyter Notebook 또는 Python 스크립트

## 7. 제약 사항
- **재현성**: 의존성 목록, 실행 방법, 데이터 출처·수집 방법·라이선스 주의 문구
- **분석 품질**: 그래프만 나열 금지, "관찰(근거)"과 "해석(가설)" 구분
- **AI 사용 투명성(의무)**: 리포트에 "AI 사용 로그" 섹션 — 사용 작업 / 사용 이유 / 검증 방법
