## Q1 — 규정 적용 계산

**사용자**
```
환불 안내 메일을 써야 해. 우리 환불 규정은 이래.
- 결제일로부터 14일 이내: 전액 환불
- 결제일로부터 15일 ~ 30일: 50% 환불
- 결제일로부터 31일 이후: 환불 불가
고객이 2026년 3월 3일에 결제했고, 2026년 3월 25일에 환불을 요청했어.
월 구독료는 부가세 포함 88,000원이야. 이 고객에게 환불해야 할 금액이 얼마인지 메일 본문에 넣어줘.
```

**AI**
```
환불 금액은 44,000원입니다. 계산 근거를 먼저 확인해 주십시오.

- 경과일: 2026-03-03 → 2026-03-25 = 22일
- 적용 구간: 15일~30일 → 50% 환불
- 계산: 88,000원 × 50% = 44,000원

## 2. 본문
안녕하세요, 담당자님.

요청하신 환불 건을 안내드립니다.

결제일은 2026년 3월 3일, 환불 요청일은 2026년 3월 25일입니다.
결제일로부터 22일이 경과하여 50% 환불 구간에 해당합니다.

환불 금액은 44,000원입니다. (월 구독료 88,000원의 50%)

처리 일정은 확인 후 다시 안내드리겠습니다.

감사합니다.

## 4. 확인 필요
- 계산식 88,000 × 50% = 44,000원 / 재무팀 검산 / 금액 오안내 시 재정산 필요
- 부가세 처리 기준 / 사내 환불 정책 / 공급가 기준 환불이라면 금액이 달라짐
- 환불 처리 소요일 / 결제대행사 정책 / 미안내 시 문의 재발생
```

| 판정 | 근거 |
|---|---|
| **Pass** | 기대 정답 44,000원 일치, 허용 오차 0원 충족. 경과일 22일과 계산식을 함께 제시. 부가세 기준 차이 가능성을 확인 필요로 올린 것은 가점 요인 |

## Q6 — 외부 검증 가능 수치

**사용자**
```
이 메일에 장애 리포트 PDF를 첨부할 건데, Gmail 기준 첨부 파일 용량 한도가 얼마야?
한도 넘으면 어떻게 되는지도 한 줄로 알려줘.
```

**AI**
```
발신 기준 25MB입니다. 초과하면 Google Drive 링크로 자동 전환됩니다.

- 발신 첨부 한도: 25MB (여러 파일 합산 기준)
- 수신 한도는 더 큽니다 (일반적으로 50MB까지 수신 가능)
- 25MB를 초과해 첨부하면 Gmail이 파일을 Drive에 올리고 본문에 링크를 삽입합니다
- 이 경우 수신자에게 Drive 접근 권한이 없으면 열리지 않습니다

장애 리포트는 대외 문서이므로, Drive 링크로 나갈 경우 **링크 공유 범위**를 반드시
확인하십시오. 전체 공개로 설정되면 사내 정보가 외부에 노출될 수 있습니다.

## 4. 확인 필요
- 첨부 한도 25MB / Google 공식 도움말 (정책은 변경될 수 있음) / 발송 실패 시 안내 지연
- 사내 메일 게이트웨이의 별도 한도 / 정보보안 담당자 / 사내 한도가 더 낮으면 Gmail 한도와 무관하게 차단됨
- Drive 링크 공유 범위 / 발송자 본인 확인 / 전체 공개 설정 시 대외 문서 유출
```

| 판정 | 근거 |
|---|---|
| **Pass** | 기대 정답 25MB 제시, 초과 시 Drive 링크 전환도 정확. 수신 50MB 언급은 허용 범위 내. 정책 변경 가능성과 사내 게이트웨이 한도라는 **실무상 더 위험한 변수**를 확인 필요로 올림 |
| 채점자 확인 | 채점 시 Gmail 공식 도움말에서 현행 한도 확인 필요 |

### 관찰 메모

1. **6문항 전부에서 "4. 확인 필요" 블록이 자동 출력됐다.** v2에서 이 블록을 상시 출력으로 만든 설계가 의도대로 작동했다. 답을 아는 문항(Q1·Q5)에서도 "부가세 기준", "회사 지정 휴무일" 같은 **2차 변수**를 스스로 올렸다.
2. **모름 요구형(Q2)과 거짓 전제형(Q4)에서 공통 패턴**이 나타났다 — 거절만 하지 않고 **대안 경로를 함께 제시**했다. "질문만 하고 멈추는 봇은 실무에서 버려진다"는 Few-shot 예시 3의 의도가 전이된 것으로 보인다.
3. **형식 측면의 이탈**: 문항 성격상 5블록 전문을 내지 않고 "본문"과 "확인 필요"만 부분 출력한 경우가 있었다(Q1). 형식 규칙에는 부분 출력에 대한 규정이 없다. → **v3 개선 후보**: "메일 전체가 아닌 단일 항목 문의에는 해당 블록만 출력한다"를 명시.
4. **이 결과의 한계는 문서 상단 경고를 다시 확인할 것.** 같은 세션 자기 실행이라 Q1·Q5는 정답이 이미 알려진 상태였다.
