# 나만의 프롬프트 관리 (Prompt Manager)

이전 미션에서 만든 프롬프트를 한곳에 모아두고 검색·분류·즐겨찾기로 관리하는
파이썬 콘솔 프로그램입니다.

메모장과 노션, 메신저에 흩어져 있던 프롬프트를 "그때 그 프롬프트 어디 갔지?" 없이
바로 꺼내 쓰는 것이 목표입니다.

---

## 실행 방법

Python 3.10 이상이 필요합니다. 외부 라이브러리는 쓰지 않습니다.

```bash
python3 --version        # 3.10 이상인지 확인
python3 prompt_manager.py
```

VSCode에서는 `prompt_manager.py`를 열고 오른쪽 위 ▶ 실행 버튼을 눌러도 됩니다.

프로그램이 뜨면 메뉴 번호를 입력해 기능을 고르고, `0`을 누르면 종료됩니다.
없는 번호를 넣으면 안내 문구를 보여주고 메뉴로 돌아옵니다.

```
=== 나만의 프롬프트 관리 ===
1. 프롬프트 추가
2. 프롬프트 목록
3. 카테고리별 조회
4. 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 관리
7. 즐겨찾기 목록
8. 프롬프트 수정
9. 프롬프트 삭제
10. 조회수 TOP
11. JSON 파일로 저장
12. JSON 파일에서 불러오기
13. 카테고리별 마크다운 내보내기
0. 종료
선택:
```

## 기능 목록

### 필수 기능

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력받아 등록합니다. 빈 값이면 다시 물어봅니다. |
| 2 | 프롬프트 목록 | 번호, 카테고리, 제목, 즐겨찾기(⭐)를 한 줄로 보여줍니다. |
| 3 | 카테고리별 조회 | 카테고리를 골라 그 카테고리의 프롬프트만 봅니다. |
| 4 | 프롬프트 검색 | 제목과 내용에서 키워드를 찾습니다. 대소문자를 구분하지 않습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 넣으면 내용 전체를 보여줍니다. |
| 6 | 즐겨찾기 관리 | 같은 번호를 다시 넣으면 해제되는 토글 방식입니다. |
| 7 | 즐겨찾기 목록 | ⭐가 켜진 프롬프트만 모아 봅니다. |

### 보너스 기능

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| 8 | 프롬프트 수정 | 엔터만 누르면 기존 값을 그대로 둡니다. |
| 9 | 프롬프트 삭제 | 제목을 확인시키고 `y`를 받아야 지웁니다. |
| 10 | 조회수 TOP | 상세 보기로 많이 열어 본 순서로 최대 5개를 보여줍니다. |
| 11 | JSON 저장 | 현재 목록을 `prompts.json`에 저장합니다. |
| 12 | JSON 불러오기 | `prompts.json`에서 목록을 되불러옵니다. |
| 13 | 마크다운 내보내기 | `export/<카테고리>.md` 파일을 카테고리마다 만듭니다. |

> 프롬프트는 기본적으로 **프로그램 실행 중에만** 메모리에 유지되고 종료하면 초기화됩니다.
> 남겨두고 싶을 때만 11번으로 저장하고 다음 실행에서 12번으로 불러오면 됩니다.

## 등록된 프롬프트 카테고리

카테고리는 아래 6개가 기본으로 준비되어 있고, 추가할 때 `0. 직접 입력`을 고르면
목록에 없는 이름도 쓸 수 있습니다.

| 카테고리 | 어떤 프롬프트를 넣는가 | 기본 데이터 |
| --- | --- | --- |
| 텍스트 생성 | 글·메일·문서 초안을 뽑는 지시문 | 서비스 장애 사과 메일 초안 요청 |
| 이미지 생성 | 이미지 모델용 키워드·구도·조명 묘사 | 여백 글래스 스킨 모델 비주얼 |
| 영상 생성 | 영상 모델용 카메라 무빙·질감 묘사 | 여백 쿠션 제품 리빌 컷 (veo 3.1) |
| 페르소나 | 역할·목표·출력 형식을 정의한 시스템 프롬프트 | 메일라이트(MailWright) 업무 메일 어시스턴트 |
| 자동화 | 워크플로우 설계·도구 비교를 요청하는 지시문 | 뉴스레터 구독 웹훅 분기 워크플로우 설계 |
| 기타 | 위 어디에도 들어가지 않는 것 | (비어 있음) |

기본 데이터 5개는 모두 이전 미션에서 실제로 작성해 사용했던 프롬프트입니다.

## 데이터 구조

프롬프트 하나는 딕셔너리, 전체 목록은 리스트로 관리합니다.

```python
prompts = [
    {
        "title": "여백 쿠션 제품 리빌 컷 (veo 3.1)",
        "content": "Cinematic macro video shot of a pure white...",
        "category": "영상 생성",
        "favorite": True,
        "views": 0,
    },
]
```

목록에 붙는 번호는 **항상 전체 목록 기준**입니다.
그래서 검색 결과에 `3번`으로 뜬 프롬프트를 상세 보기에서도 `3`으로 열 수 있습니다.

## 코드 구조

모든 기능은 함수로 나눠져 있고, `main()`은 메뉴 번호를 받아 해당 함수를 부르기만 합니다.

| 함수 | 역할 |
| --- | --- |
| `show_menu()` | 메뉴 출력 |
| `main()` | 입력 반복 루프와 분기 |
| `input_required()` | 빈 값이면 다시 물어보는 입력 도우미 |
| `choose_category()` | 카테고리 선택 / 직접 입력 |
| `select_prompt()` | 번호 검증 후 프롬프트 반환 |
| `numbered_prompts()` / `format_summary()` / `print_prompts()` | 목록 출력 공통 처리 |
| `add_prompt()` / `edit_prompt()` / `delete_prompt()` | 등록·수정·삭제 |
| `show_list()` / `show_by_category()` / `search_prompt()` / `show_detail()` | 조회 |
| `toggle_favorite()` / `show_favorites()` | 즐겨찾기 |
| `show_top_viewed()` | 조회수 정렬 |
| `save_to_json()` / `load_from_json()` / `export_markdown()` | 파일 입출력 |
